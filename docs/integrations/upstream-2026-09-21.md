## Independent review

Review identified and verified corrections for stale admission validation after execution barriers, stop without terminal-event reservation release, storage deletion before admission release, missing timeline plan-command projection, and duplicate publishing guards. Follow-up review approved these changes, bounded SQL lookup batching, SDK runtime subpath packaging, and the final contract/fixture corrections. The fresh-install package smoke expectation was independently reviewed as well. Independent review also approved the action-only dialog splits and all seven full-suite fixture corrections. No unresolved material finding remained in those reviews.

The subsequent Codex PR review found that the server-move view could disappear while its chunk loaded. Its blocking shell, status, focus management, recovery and abandon controls now render eagerly; only optional step details are deferred with the shared frame/timeout realization. Pending and rejected chunk regressions retain the same shell and working controls. Notification and section-form content remain behind eager shells to preserve the unchanged bundle budgets. All 18 focused UI tests and app build/typecheck/lint passed, and independent follow-up review approved the changes. The comment audit removed 42 non-declaration explanatory blocks introduced by the integration while retaining semantic directives and public Plugin SDK documentation; emitted JS/CSS and workflow values were unchanged, and seven CLI organization tests passed.

The follow-up security review found that custom and Connect server renderers could access privileged desktop browser operations. Browser IPC now requires a registered main frame at the actual built-in runtime origin; the broker applies the same authority checks and disconnects from non-local targets. Top-level navigation revokes browser-control leases and rotates the instance generation, with discovery refreshed after trusted loading completes. Cookie imports through both renderer and broker require a native, deny-by-default confirmation scoped to the source browser/profile and destination. Approval expires after ten seconds, and document/target authority is checked again after asynchronous work and before cookie writes. Retained tabs cannot forward events to untrusted renderers, and application windows register before initial navigation so trusted startup calls remain available. CLI and Plugin Guide documentation describe the restriction. No server/daemon wire fields changed. The final desktop suite passed 421 tests with one skipped, including real Electron startup; desktop build/typecheck passed all 51 tasks, and Plugin Guide checks passed all 76 tests. Initial sandboxed native startup failed and an initial outside-sandbox startup timed out; the isolated smoke and subsequent complete suite passed. These tests do not substitute for manual native consent-dialog QA.
